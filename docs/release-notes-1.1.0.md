## افزوده‌ها و اصلاح‌ها (نسبت به 1.0.0)

### پایداری و عملکرد
- مهلت و لغو یکسان برای همهٔ درخواست‌های API؛ پاسخ کهنه دادهٔ جدید را بازنویسی نمی‌کند.
- بازیابی SSE با Backoff نمایی، بافر محدود و Watchdog سکوت.
- API اختصاصی نقشه با bbox، شمارش مستقل مختصات و پشتیبانی از هزاران Marker.
- پردازش Excel و MBTiles در Worker با صف محدود، هم‌زمانی و مهلت.
- بهینه‌سازی گزارش‌ها و فهرست تجهیزات با تجمیع JOIN و ایندکس.
- وضعیت مستقل سرور/موتور/تجهیزات، Error Boundary و جلوگیری از ثبت دوباره.

### کیفیت و امنیت
- پوشش قراردادی ۱۰۷ Endpoint با فهرست بسته.
- تست هم‌زمانی دیتابیس، Flap شبکه، ۱۰۰ اتصال SSE، ورود ۵۰٬۰۰۰ ردیف.
- تست WAL/Checkpoint، دیسک پر، Backup/Restore و Rollback.
- اصلاح پاسخ ۵۰۰ برای صفحه‌گستردهٔ خراب، حفظ ۵۰۷ در دیسک پر و سقف پاسخ پیش‌نمایش.
- `npm audit` بدون آسیب‌پذیری.

### عملیات
- هارنس‌های `qa:load`، `qa:soak`، `qa:soak24`، `qa:soak72` و `test:heavy`.
- اسکریپت `release:prepare` برای پشتیبان پیش از انتشار، آرشیو نسخهٔ قبلی و مانیفست Rollback.
- گزارش‌های QA، عملکرد، امنیت و Runbook انتشار.
