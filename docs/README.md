## وضعیت قابلیت‌ها

سه برچسب در سراسر مستندات استفاده می‌شود:

| برچسب | معنی |
| --- | --- |
| **موجود** | در کد پیاده‌سازی شده و مسیر اجرایی دارد |
| **موجود با محدودیت** | پیاده‌سازی شده اما شرط/سقف/نقص شناخته‌شده دارد |
| **آزمون محیطی لازم** | پیاده‌سازی شده ولی تأیید نهایی به محیط واقعی نیاز دارد |

**قابلیت‌های حذف‌شده که نباید به‌عنوان قابلیت فعال معرفی شوند:**

- **SNMP** (پایش ترافیک اینترفیس، OID، community، Poll سنجش لینک) — کامل حذف شد:
  ماژول، Route، محیط، ستون‌ها، جدول و آزمون‌ها. مهاجرت ۱۱ باقی‌ماندهٔ آن را از
  پایگاه‌دادهٔ قدیمی پاک می‌کند.
- ارسال ایمیل/SMS/Webhook؛ اعلان‌ها فقط درون برنامه‌اند.
- MFA، LDAP/AD، SSO.
- اجرای چندنمونه‌ای افقی روی SQLite مشترک (محدودیت معماری).
- رمزنگاری داده در حالت سکون یا رمزنگاری پشتیبان.

## قراردادها

- همهٔ زمان‌ها **epoch milliseconds** هستند مگر خلافش ذکر شود.
- مسیر فایل‌ها نسبی به ریشهٔ مخزن است؛ مثل `server/engine.js`.
- نمونه‌های JSON «شکل پاسخ» هستند و ممکن است فیلد بیشتری داشته باشند.
- مقادیر حساس با `…` نمایش داده می‌شوند.
